# לכל קול — אתר תצוגה לקלינאות תקשורת

אתר נחיתה רספונסיבי בעברית (RTL), ללא תלות ב־npm, מסד נתונים או שירות בתשלום. קובץ `index.html` כולל את העיצוב, התוכן והתנהגות האתר. אפשר לפתוח אותו בדפדפן או להעלות ל־Vercel בתור אתר סטטי.

## פרטים שחובה להשלים לפני פרסום ללקוחות

1. שם הקלינאית ומספר הוואטסאפ עודכנו בהתאם לפרטים שסופקו: `נעמה ויליאן` ו־`050-3091999`. המספר מוגדר בתוך `SITE` כ־`972503091999`, וכפתורי הפנייה פותחים WhatsApp עם הודעה מותאמת למסלול הטיפול. מומלץ לאמת את הפרטים מול הלקוחה לפני פרסום פומבי.
2. אשרו מול נעמה את התואר המקצועי, פרטי ההכשרה, הרישוי והכתובת המלאה של הקליניקה, והשלימו פרטים חסרים.
3. החליפו את תמונות ההמחשה בתמונות אמיתיות של המטפלת או בתמונות שהותר שימושן. הימנעו מזיהוי מטופלים ללא הסכמה מתאימה.
4. אשרו את תחומי הטיפול והניסוחים המקצועיים, כולל טיפול בתפקודי פה והתאמה לזום.
5. חברו דומיין, פרטי מטא ו־OG מותאמים, פרטי מדידה לפי הצורך והודעות פרטיות חוקיות לפני הפצה רחבה.

## התנהגות כפתורי הפנייה
כל כפתורי הפנייה מתאימים את הודעת הוואטסאפ לתחום הטיפול. עד להזנת מספר תקין נפתח חלון הדגמה שאפשר להעתיק ממנו הודעה; פניות אינן נשלחות. האתר אינו שומר פרטי מטופלים ואין בו טופס איסוף מידע רפואי.

האתר משתמש באופן זמני בתמונות להמחשה מאתר Pexels ולא בתמונות הלקוחה. דפי המקור:

התמונות נטענות מכתובות CDN חיצוניות, ולכן דרוש חיבור לאינטרנט להצגתן. מומלץ להחליף לתמונות מאושרות של הלקוחה לפני השקה.

## פיתוח והעלאה
